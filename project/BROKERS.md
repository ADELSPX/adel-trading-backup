# مقارنة الوسطاء للبوت — القرار: IBKR

حُسمت 2026-10-31 بناءً على بحث موثّق وإجابات عادل.

| الوسيط | ربط آلي لبوت خارجي | السوق الأمريكي | الحكم |
|---|---|---|---|
| **IBKR** | TWS API + IB Gateway + Client Portal REST — رسمي وناضج، مكتبات بايثون جاهزة، حساب ورقي مطابق للحقيقي | كامل: أسهم وخيارات SPX/SPY وغيرها، بيانات يونانيات (قاما) من سلسلة الخيارات نفسها | **الأساس المعتمد للبوت** — حساب عادل مفعّل وجاهز عنده |
| دراية المالية | ربط TradingView للتنفيذ اليدوي من الشارت (سوق سعودي)؛ لا API عام موثّق لربط بوت خارجي بالسوق الأمريكي | عبر «دراية جلوبل» يدويًا | لا تصلح قاعدة للبوت |
| أبيان المالية (Abyan) | تطبيق استهلاكي؛ بنيته التحتية Alpaca Broker API (لأبيان نفسها لا للعملاء)، ومساعد «أبيان AI» داخل التطبيق للتحليل لا لتنفيذ بوتات خارجية؛ لم يُعثر على API عام لحسابات العملاء | أسهم أمريكية عبر ألباكا | لا تصلح قاعدة للبوت حاليًا |

ملاحظات:
- عمولة خيارات IBKR تقارب 0.65$ للعقد — مع رأس بداية 150$ يبقى التنفيذ ممكنًا بعقد واحد رخيص في كل مرة (SPY أسبوعي قريب من السعر)، والمخاطرة عالية وإمكان خسارة كامل المبلغ واردة؛ لذلك الاختبار الورقي أولًا إلزامي.
- التشغيل: سيرفر عادل يستضيف البوت + IB Gateway (تسجيل الدخول والتحقق بخطوتين مسؤولية عادل دوريًا).
- بديل مستقبلي إن أراد مسارًا ثانيًا: حساب مباشر لدى Alpaca (Trading API ممتاز للبوتات + ورقي مجاني) — وهي البنية نفسها التي تعمل عليها أبيان.
