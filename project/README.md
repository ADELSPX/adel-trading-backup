# مشروع التداول — نظرة عامة

- صاحب المشروع: عادل (ابوجهاد)
- الهدف: إنشاء مشروع تداول مبني على فحص قناة يملكها عادل، وتحويل محتواها إلى استراتيجية تداول واضحة القواعد وقابلة للاختبار.
- الحالة (2026-10-30): مرحلة التأسيس.
  - تم: إنشاء مستودع النسخ الاحتياطي الخاص وتفعيل وصول الوكيل إليه.
  - بانتظار عادل: رابط القناة ومنصتها والسوق المستهدف، لبدء الفحص.
- مكونات المشروع:
  - `CHANNEL_EXAMINATION.md` — خطة فحص القناة ونتائجه.
  - `STRATEGY.md` — قواعد الاستراتيجية المستخرجة بعد الفحص.
- قاعدة عمل: لا اعتماد على أي استراتيجية قبل اختبارها على بيانات سابقة وتقييم مخاطرتها.
