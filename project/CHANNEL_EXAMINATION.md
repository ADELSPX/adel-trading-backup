# فحص القناة

- الحالة: بانتظار رابط القناة من عادل (المنصة والسوق المستهدف غير معروفين بعد).

## ما سيُفحص
1. طبيعة المحتوى: توصيات، تحليل، صفقات — وهل توجد نقاط دخول وخروج ووقف وهدف واضحة وقابلة للقياس.
2. الأداء الفعلي: نسبة نجاح الصفقات، متوسط الربح مقابل متوسط الخسارة، أكبر تراجع (drawdown).
3. إدارة المخاطرة: حجم المخاطرة لكل صفقة، تكرار التوصيات، والثبات عبر ظروف سوق مختلفة.
4. قابلية التحويل إلى قواعد: هل يمكن صياغة المحتوى كقواعد استراتيجية دقيقة قابلة للاختبار الآلي على بيانات سابقة (backtest).
